# 그리드 월드 AI 데모

이 저장소는 인공지능이 갖춰야 할 핵심 개념적·기술적 조건을 한 번에
체험할 수 있는 예제를 제공합니다. 에이전트는 작은 격자(Grid World)
환경에서 다음 기능을 보여줍니다.

- **학습**: Q-러닝으로 최적의 행동 전략을 학습합니다.
- **지각**: 주변 장애물과 목표물, 충전소 위치를 감지합니다.
- **추론**: 규칙 기반 시스템으로 현재 상황을 해석합니다.
- **문제 해결**: A* 탐색으로 최적 경로를 계산합니다.
- **정책-계획 통합**: Q-러닝 정책과 탐색 경로를 비교해 더 효율적인 행동을 고릅니다.
- **언어 이해**: 한국어/영어 명령을 해석해 의도와 목표를 추출합니다.
- **자율성**: 배터리 상태를 고려하며 스스로 행동을 선택합니다.

## 실행 방법

### 1. 한국어 요약 출력 (기본)

```bash
python -m ai_system.main
```

명령 세 개를 순차적으로 실행한 뒤, 한국어로 해석·추론·계획 결과를
요약해 보여줍니다. JSON 형식이 필요하면 `--format json` 옵션을 추가하세요.

```bash
python -m ai_system.main --format json
```

직접 명령을 지정하고 싶다면 실행 시 인자를 나열하면 됩니다.

```bash
python -m ai_system.main "목표 지점으로 이동" "상태 보고" "충전소로 가"
```

### 2. 대화형 한국어 콘솔

```bash
python -m ai_system.cli
```

콘솔에 한국어나 영어 명령을 입력하면 에이전트가 실시간으로 판단한
계획과 행동을 한국어로 설명해줍니다. `종료`, `quit`, `exit` 명령으로
프로그램을 종료할 수 있습니다.

## 깃허브 업로드 안내

이 저장소를 자신의 깃허브로 올리고 싶다면 아래 순서를 따르면 됩니다.

1. 깃허브에 새 빈 저장소를 만든 뒤 원격 주소(URL)를 복사합니다.
2. 이 프로젝트 루트에서 다음 명령으로 원격을 추가합니다.

   ```bash
   git remote add origin <깃허브_저장소_URL>
   ```

3. 현재 브랜치(`work`)에 있는 커밋을 푸시합니다.

   ```bash
   git push -u origin work
   ```

   기본 브랜치를 `main`이나 `master`로 사용하고 싶다면 `git branch -M main`
   명령으로 브랜치 이름을 바꾼 후 `git push -u origin main`으로 푸시하면
   됩니다.

이 과정을 마치면 깃허브에서 코드를 확인하고 Pull Request를 생성하거나
워크플로우를 구성할 수 있습니다.

### CLI에서 바로 업로드 시도하기

대화형 콘솔(`python -m ai_system.cli`)에서 `"깃허브에 올려줘"`라고 입력하면
현재 브랜치를 원격으로 푸시하려고 시도합니다. 아직 원격을 설정하지 않은
경우에는 필요한 명령을 안내합니다. 푸시 전에 상태만 확인하려면
`"깃허브 상태 확인"`과 같이 요청하세요.

또는 다음 명령으로 동일한 기능을 사용할 수 있습니다.

```bash
python -m ai_system.github --dry-run  # 상태 확인
python -m ai_system.github            # 실제 푸시 시도
```
