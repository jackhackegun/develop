# 그리드 월드 AI 데모

이 저장소는 인공지능이 갖춰야 할 핵심 개념적·기술적 조건을 한 번에
체험할 수 있는 예제를 제공합니다. 에이전트는 작은 격자(Grid World)
환경에서 다음 기능을 보여줍니다.

- **학습**: Q-러닝으로 최적의 행동 전략을 학습합니다.
- **지각**: 주변 장애물과 목표물, 충전소 위치를 감지합니다.
- **추론**: 규칙 기반 시스템으로 현재 상황을 해석합니다.
- **문제 해결**: A* 탐색으로 최적 경로를 계산합니다.
- **정책-계획 통합**: Q-러닝 정책과 탐색 경로를 비교해 더 효율적인 행동을 고릅니다.
- **언어 이해**: 한국어/영어 명령을 해석해 의도와 목표를 추출합니다.
- **자율성**: 배터리 상태를 고려하며 스스로 행동을 선택합니다.

## 실행 방법

### 1. 한국어 요약 출력 (기본)

```bash
python -m ai_system.main
```

명령 세 개를 순차적으로 실행한 뒤, 한국어로 해석·추론·계획 결과를
요약해 보여줍니다. JSON 형식이 필요하면 `--format json` 옵션을 추가하세요.

```bash
python -m ai_system.main --format json
```

직접 명령을 지정하고 싶다면 실행 시 인자를 나열하면 됩니다.

```bash
python -m ai_system.main "목표 지점으로 이동" "상태 보고" "충전소로 가"
```

### 2. 대화형 한국어 콘솔

```bash
python -m ai_system.cli
```

콘솔에 한국어나 영어 명령을 입력하면 에이전트가 실시간으로 판단한
계획과 행동을 한국어로 설명해줍니다. `종료`, `quit`, `exit` 명령으로
프로그램을 종료할 수 있습니다.
